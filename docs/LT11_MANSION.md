# 東京は何階建て？（TOKYO MANSION）― LT11 プロトタイプ

ブランチ：`lt11-mansion`（`main` の PLATEAU Vertical Atlas から分岐した独立プロトタイプ）
発表：PLATEAU LT11（2026年10月28日・約5分）

> **「港区の高層階と、多摩の地面は、同じフロア？」**
> 東京都をひとつの巨大マンションに見立て、海抜10mごとに1フロアを割り当てて、港区の超高層と多摩の地面を同じ絶対標高で比べます。

## ルール

| 項目 | 定義 |
| --- | --- |
| 仮想フロア | `floor = floor(標高 / 10) + 1`（海抜0m以上）。1F＝0〜10m、8F＝70〜80m、15F＝140〜150m。0m未満は B1F |
| 代表高度 | 各フロアの帯の中央（8F → 海抜75m）。この高さで水平に切った断面を使う |
| セルの分類 | 建物（PLATEAUボクセル）／地盤（DEMの地表面より下）／空室＝自由空間／未整備・判定不能（PLATEAU整備範囲外・DEMなし） |
| 仮想空室率 | 空室セル ÷（建物＋地盤＋空室）× 100。**代表高度1枚の面積割合**。未整備は分母から除外。実際の住宅の空室率ではない |

仮想フロアは比較のための番号で、実在の建物の階数・階高とは無関係です（画面上部と物件概要に明記）。

## 物件（実データ）

| | 港区 芝浦 | 多摩 立川 |
| --- | --- | --- |
| 範囲 | 芝浦アイランド・田町駅東口 512m四方 | 立川駅北口 512m四方 |
| 建物 | PLATEAU 2025年度 港区（メッシュ 53393569 / 53393660 / 53393579 / 53393670）269棟 | PLATEAU 2025年度 立川市（メッシュ自動判定）388棟 |
| 地盤（DEM5A） | 海抜 −0.5〜5.3m（中央値 3.2m → 1F） | 海抜 81.8〜85.7m（中央値 83.7m → 9F） |
| 格子 | 256×256×88、水平2m・鉛直2m、海抜0m起点 | 256×256×107、同左 |

PLATEAU整備範囲（`coverage`）は両範囲とも100%、DEMの欠損は0セルです。

### データで確認した事実（LOD2）

| フロア | 港区 芝浦 | 多摩 立川 |
| --- | --- | --- |
| 1F（代表5m） | 建物26.4%・空室73.2% | 地盤100% |
| 8F（代表75m） | 建物3.7%・空室96.3%（地上47階・計測高さ170mの共同住宅の約21階） | **地盤100%（まだ地面の中）** |
| 9F（代表85m） | 建物3.2%・空室96.8%（同じ建物の約24階） | 地盤5.8%・建物48.4%・空室45.7%（ここが地上＝玄関の階） |
| 15F（代表145m） | 建物1.8% | 建物0.6% |

階の推定は「計測高さ ÷ 地上階数」によるもので、画面では「推定」と表示しています。

## 画面

- **フロア案内（左）**：エレベーターの表示器と▲▼・自動運転。各フロアの港区／多摩の構成（地盤・建物・空室）を案内板の帯で表示し、クリックでその階へ
- **モデルルーム（中央上）**：2つの範囲を同じ縮尺・同じ絶対標高で横に並べた3D展示。地盤は土のブロック（10mごとのフロア線）、建物はPLATEAU LOD2。現在のフロア帯を金色で表示し、中央の定規でフロア番号を表示
- **フロアマップ（中央下・左右）**：代表高度の水平断面を4分類で表示。仮想空室率、構成比、「この階は何か」の一言説明。クリックで地点の地面標高・建物名・推定階を表示
- LOD1 / LOD2 切替、`▶ LTデモ`、物件概要・出典

並べて展示しているのは比較のためで、実際の位置関係ではありません（高さは共通の絶対標高）。

#### 物件を追加する

```bash
python3 -m pip install -r pipeline/requirements.txt
npm run mansion:add -- <id> <経度> <緯度> <区分> <地名>
#   例) npm run mansion:add -- tama-tamacenter 139.4237 35.6250 多摩 多摩センター
```

中心から512m四方を、PLATEAUデータカタログAPIで自動判定したメッシュのCityGMLから2m×2m×2mでボクセル化し（1エリア約2分）、`public/data/mansion.json` の選択肢に追加します。
ブラウザの中で任意の地点をその場で作ることはできません（CityGMLの取得とボクセル化が必要なため）。PLATEAU 2025年度の整備範囲外は「未整備」になります。

### エレベーターの速さ

エレベーター表示器の下で切り替えます（設定はブラウザに保存）。移動時間は加速度 2m/s² の台形パターン（短い移動は三角形）で計算し、表示器は通過する階を数え上げます。自動運転は到着後0.9秒止まってから次の階へ進みます。

| 速さ | 定格速度 | 1フロア（10m） | 1F→9F（80m） |
| --- | --- | --- | --- |
| ゆっくり | 1.5 m/s（分速90m・中低層マンション程度） | 約7.4秒 | 約54秒 |
| 超高層（既定） | 6 m/s（分速360m・タワーマンション程度） | 約4.5秒 | 約16秒 |
| 高速 | 10 m/s（分速600m・展望台などの高速エレベーター） | 約4.5秒 | 約13秒 |
| 一瞬 | ― | 0.4秒 | 0.9秒 |

LTで時間が限られる場合は「一瞬」か「高速」が向いています。

### エレベーターの音

Web Audio で合成しています（音源ファイルなし）。ヘッダーの「音」ボタンで「なし／チャイム／アナウンス」を切り替えます（設定はブラウザに保存）。

| 音 | 内容 |
| --- | --- |
| 到着チャイム | 880Hzの鐘の音。上りは1回、下りは2回（0.42秒間隔）。自動運転中は控えめの音量 |
| 移動中 | 110Hz前後のモーター音。移動距離に応じて長さが変わる |
| ボタン | 1760Hzの短いビープ |
| アナウンス | 「アナウンス」選択時のみ。ブラウザの日本語音声合成で「8階です」（声は端末によって異なる） |

ブラウザの仕様で、ページを一度タップ／クリックするまでは鳴りません。LTではデモ開始時にクリックすれば以降は鳴ります。iPhoneはマナーモード（消音スイッチ）だと鳴らないことがあります。

## 共通基盤との関係

再利用（変更なし、または追加のみ）：
- パイプライン：CityGML解析・LOD1/LOD2ボクセル化・DEM取得・Zarr書き出し・ENU変換（`pipeline/atlas/*`）
- ブラウザ：`Atlas`（zarrita による Zarr 読み込み、1高度ずつのチャンク取得、格子⇔ENU変換）
- 解析：`occupancy[z, y, x]` の水平断面

このブランチで追加：
- `pipeline`：メッシュの自動判定、PLATEAU整備範囲 `coverage[y, x]`、地形ブロックの glTF（`terrain.glb`）、絶対標高の建物 glTF（`lod*_abs.glb`）
- `src/mansion/*`：フロア計算・4分類・空室率（`floors.ts`、単体テストあり）、3Dモデルルーム、UI
- `Atlas` が任意の `coverage` レイヤーを読む（無ければ従来どおり）

地層図・天空ダンジョン・空の抜け道・全国比較は今回は実装していません（デモ最後のスライドで構想として紹介）。

## 既知の制約

- 対象は建築物（bldg）のみ。高架・橋梁・樹木などは含みません。水面はDEMの値をそのまま地面として扱います
- 建物は2mセルの中心で判定。細い部材・屋上突起は欠落することがあります
- 「立川北駅」のオブジェクトは計測高さ約128mの塔状部分を含み、LOD1とLOD2の上端が大きく異なります。PLATEAUの属性をそのまま表示し、地点情報で確認推奨と注記しています（フロアの一言説明では除外）
- 芝浦の超高層はPLATEAU上で名称が未登録のため「名称未登録の建物（共同住宅）」と表示します
- 3Dの断面は、地盤の中にある場合は土のブロックに隠れて見えません（フロアマップで確認）
- ヘッドレス環境（SwiftShader）で確認しています。会場の機材での描画の滑らかさは要確認
