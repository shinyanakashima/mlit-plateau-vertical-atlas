# LT実演シナリオ（5分）

PLATEAU LT11（2026年10月28日）
「東京の空は、何メートルからつながるのか？ ― PLATEAU × Zarrで街を水平に輪切りにしてみた」

## 起動

```bash
npm run build && npx vite preview --port 4173      # 本番ビルドで確認する場合
# ブラウザで http://localhost:4173/?tour  （公開URLなら https://<host>/?tour）
```

- `?tour` でガイド付きデモが1枚目から始まります。`→` / `PageDown`（プレゼンター用クリッカー）で次、`←` / `PageUp` で前、`Esc` で終了
- ブラウザはフルスクリーン（F11）。1920×1080 または 1600×900 を推奨
- 画面右上の「Zarr 82/82 高度」がそろえば、全高度の解析が完了しています

## 想定質問

- **なぜZarr？** 3次元の格子を高さ方向にチャンク分割でき、ブラウザから必要な高さだけを静的ファイルとして取れる。サーバーもタイル生成も不要で、R2などのオブジェクトストレージにそのまま置ける
- **4近傍の理由は？** 斜めの角接触（建物の角どうしの隙間0m）を「通れる」と数えないため。離隔の設定と組み合わせて通路の幅を表す
- **範囲の端は？** 外周の帯を除外する設定で、縁を回り込むだけの見かけの連結を確認できる。範囲外の建物は考慮していないことも制約として明示
- **ドローンに使える？** 建物形状だけの幾何学的な解析で、航空法・飛行禁止区域・気象・電波・第三者上空などは考慮していない。飛行の安全性や可否は保証しない
